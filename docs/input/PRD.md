# 제품 요구사항 (PRD)

상태: 초안

## 1. 제품 개요

### 제품명
TODO App

### 목적
사용자가 해야 할 일을 날짜별로 관리하고, 사용자가 직접 정의한 종류(카테고리)로 분류하며, 완료 여부에 따라 필요한 일정만 확인하고, 지정한 시점에 알림을 받을 수 있는 Android TODO 애플리케이션을 만든다.

### 대상 플랫폼
- Android

### 대상 사용자
- 개인 일정과 업무 일정을 하나의 앱에서 간단하게 관리하고 싶은 사용자
- 날짜별 TODO 관리가 필요한 사용자
- 고정된 분류가 아니라 자신만의 종류를 만들어 관리하고 싶은 사용자
- 일정 전에 알림을 받고 싶은 사용자

---

## 2. 제품 목표

첫 번째 버전(MVP)은 다음 사용자 가치를 제공하는 것을 목표로 한다.

- 오늘 또는 특정 날짜에 해야 할 일을 빠르게 확인할 수 있다.
- TODO를 사용자가 정의한 종류로 구분할 수 있다.
- 완료되지 않은 TODO만 모아서 확인할 수 있다.
- 중요한 TODO를 잊지 않도록 사전 알림을 받을 수 있다.
- 앱을 종료한 이후에도 저장한 데이터를 계속 사용할 수 있다.

---

## 3. 핵심 사용자 흐름

### 3.1 TODO 등록

1. 사용자가 TODO 추가를 선택한다.
2. 제목과 날짜를 입력한다.
3. 필요하면 시간과 종류를 지정한다.
4. 시간이 지정된 경우 알림을 선택할 수 있다.
5. 저장한다.
6. 저장한 TODO가 해당 날짜의 목록에 표시된다.

### 3.2 날짜별 TODO 확인

1. 앱을 실행한다.
2. 기본적으로 오늘 날짜의 TODO를 확인한다.
3. 이전 날짜 또는 다음 날짜로 이동한다.
4. 선택한 날짜의 TODO 목록을 확인한다.

### 3.3 종류별 TODO 확인

1. 사용자가 종류 필터를 선택한다.
2. 특정 종류를 선택한다.
3. 선택한 날짜와 종류 조건을 모두 만족하는 TODO만 확인한다.

### 3.4 미완료 TODO 확인

1. 사용자가 `미완료만 보기`를 선택한다.
2. 완료되지 않은 TODO만 표시된다.
3. 종류 필터와 동시에 사용할 수 있다.

### 3.5 TODO 완료

1. 사용자가 TODO를 완료 상태로 변경한다.
2. 화면에 완료 상태가 즉시 반영된다.
3. `미완료만 보기`가 활성화된 경우 해당 TODO가 목록에서 제외된다.

### 3.6 TODO 알림

1. 사용자가 TODO에 날짜와 시간을 지정한다.
2. `1일 전`, `15분 전` 중 원하는 알림을 선택한다.
3. 설정된 시점이 되면 Android 알림이 표시된다.

## 4. 확정된 제품 기능

### TODO 관리
- TODO 등록
- TODO 수정
- TODO 삭제
- TODO 완료 처리
- 완료된 TODO를 다시 미완료 상태로 변경

### 날짜별 관리
- TODO 날짜 지정
- 앱 실행 시 오늘 날짜를 기본 표시
- 이전 날짜 이동
- 다음 날짜 이동
- 선택한 날짜의 TODO 목록 표시

### 종류(카테고리) 관리
- 사용자가 종류 생성
- 종류 이름 수정
- 종류 삭제
- TODO에 종류 지정
- 종류별 TODO 필터

예시:
- 업무
- 개인
- 사적
- 약속
- 공부

위 값은 고정값이 아니며 사용자가 자유롭게 생성한다.

### 완료 여부 필터
- 전체 TODO 표시
- 미완료 TODO만 표시
- 날짜 및 종류 필터와 동시에 사용 가능

### 알림
- 시간이 지정된 TODO에 알림 설정
- `1일 전` 알림
- `15분 전` 알림
- 하나의 TODO에 복수 알림 설정 가능
- 향후 다른 사전 알림 시간을 추가할 수 있도록 확장 가능해야 함

### 데이터 유지
- TODO 로컬 저장
- 종류 로컬 저장
- 알림 설정 로컬 저장
- 앱 종료 후에도 데이터 유지
- 앱 재실행 후에도 데이터 유지

## 5. 입력 정책

### TODO

| 항목 | 필수 여부 | 설명 |
|---|---|---|
| 제목 | 필수 | TODO의 내용 |
| 날짜 | 필수 | TODO가 속하는 날짜 |
| 시간 | 선택 | TODO 예정 시간 |
| 종류 | 선택 | 사용자가 생성한 종류 |
| 알림 | 선택 | 시간이 존재하는 경우 선택 가능 |
| 완료 여부 | 시스템 관리 | 기본값은 미완료 |

### 알림

초기 제공 옵션:
- 1일 전
- 15분 전

시간이 없는 TODO에는 시간 기준 알림을 설정할 수 없다.

## 6. 기본 화면 구성

MVP는 다음 3개의 주요 화면으로 구성한다.

### 6.1 TODO 목록 화면
주요 역할:
- 날짜 확인 및 이동
- 해당 날짜 TODO 목록 표시
- 완료 상태 변경
- 미완료 필터
- 종류 필터
- TODO 등록 화면 이동
- TODO 수정 화면 이동

### 6.2 TODO 등록/수정 화면
주요 역할:
- 제목 입력
- 날짜 지정
- 시간 지정
- 종류 지정
- 알림 지정
- 저장

### 6.3 종류 관리 화면
주요 역할:
- 종류 추가
- 종류 이름 변경
- 종류 삭제

## 7. 빈 상태

다음 경우 사용자에게 명확한 빈 상태를 표시한다.

### 선택 날짜에 TODO가 없는 경우
예:
> 등록된 TODO가 없습니다.

### 필터 결과가 없는 경우
예:
> 조건에 해당하는 TODO가 없습니다.

### 종류가 없는 경우
종류 생성 기능으로 이동할 수 있도록 안내한다.

---

## 8. MVP 범위

첫 번째 버전에 포함한다.

- TODO 등록/수정/삭제
- TODO 완료/미완료 변경
- 날짜별 TODO 관리
- 사용자 정의 종류 관리
- 종류별 필터
- 미완료 필터
- 날짜 + 종류 + 완료 여부 복합 필터
- 1일 전 알림
- 15분 전 알림
- 복수 알림
- 로컬 데이터 저장
- 앱 재실행 후 데이터 유지

---

## 9. MVP 제외 범위

첫 번째 버전에서는 구현하지 않는다.

- 로그인
- 회원가입
- 서버 API
- 클라우드 동기화
- 여러 기기 간 동기화
- 일정 공유
- Google Calendar 연동
- 반복 일정
- 홈 화면 위젯
- 위치 기반 알림
- 시간이 없는 TODO의 알림
- 웹/iOS 버전

## 10. 제품 완료 기준

다음 시나리오가 모두 동작하면 MVP의 제품 요구사항을 만족한 것으로 판단한다.

1. 사용자가 새로운 종류를 생성할 수 있다.
2. 사용자가 제목과 날짜를 가진 TODO를 등록할 수 있다.
3. 필요하면 TODO에 시간과 종류를 지정할 수 있다.
4. 시간이 존재하면 `1일 전`, `15분 전` 알림을 각각 또는 동시에 설정할 수 있다.
5. 저장된 TODO가 해당 날짜 목록에 표시된다.
6. 사용자가 이전/다음 날짜로 이동할 수 있다.
7. 특정 종류의 TODO만 필터링할 수 있다.
8. 미완료 TODO만 필터링할 수 있다.
9. 종류 필터와 미완료 필터를 동시에 사용할 수 있다.
10. TODO를 완료 및 미완료 상태로 변경할 수 있다.
11. TODO를 수정할 수 있다.
12. TODO를 삭제할 수 있다.
13. 앱을 종료하고 다시 실행해도 데이터가 유지된다.
14. 지정된 알림 시점에 Android 알림이 발생한다.

---

## 11. 미확정 제품 요구사항

다음 항목은 구현 전에 별도로 확정한다.

- 종류가 지정되지 않은 TODO를 허용할지 여부
- 사용 중인 종류를 삭제할 때 기존 TODO의 처리 방법
- 완료된 TODO의 미래 알림을 즉시 취소할지 여부
- 이미 지난 날짜/시간의 TODO 등록 허용 여부
- 이미 지난 알림 시점에 대한 처리
- TODO 기본 정렬 순서
- 같은 시간의 TODO 정렬 방식
- 종류 정렬 방식
- 종류별 색상 지정 기능
- TODO 삭제 확인 UI의 구체적인 형태
