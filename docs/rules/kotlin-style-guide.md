# Kotlin 스타일 규칙

상태: 확정

- Kotlin 공식 코드 스타일을 따른다.
- 클래스와 Composable은 `PascalCase`, 함수와 변수는 `camelCase`를 사용한다.
- 변경되지 않는 값은 `val`로 선언한다.
- 공개 API에는 의미 있는 타입을 사용하고 불필요한 nullable 타입을 피한다.
- 강제 언래핑(`!!`)은 사용하지 않는 것을 원칙으로 한다.
- 예외를 무시하지 않으며 예상 가능한 실패는 명시적인 결과로 표현한다.
- 함수는 하나의 책임을 갖도록 작게 유지한다.
- 매직 넘버와 사용자 노출 문자열을 코드에 반복해서 작성하지 않는다.
- 와일드카드 import를 사용하지 않는다.
- 주석은 코드 동작을 반복하지 말고 결정 이유나 제약을 설명한다.
- 코루틴은 호출 계층의 생명주기에 맞는 scope에서 실행한다.
- `Dispatchers`가 테스트를 방해할 경우 주입 가능한 dispatcher 또는 실행 환경을 사용한다.
