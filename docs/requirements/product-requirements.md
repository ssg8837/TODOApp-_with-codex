# 제품 요구사항

상태: 확정(MVP 범위)  
원본: `docs/input/PRD.md`

## 제품 개요

TODO App은 사용자가 해야 할 일을 날짜별로 관리하고, 직접 정의한 종류(Category)로 분류하며, 완료 여부로 필터링하고, 지정 시점에 Android 알림을 받을 수 있는 로컬 우선 Android 애플리케이션이다.

대상 사용자는 개인·업무 일정을 간단히 관리하고 날짜별 TODO, 사용자 정의 분류와 사전 알림이 필요한 사용자다.

## MVP 목표

- 오늘 또는 선택 날짜의 TODO를 빠르게 확인한다.
- TODO를 사용자가 정의한 종류로 분류한다.
- 미완료 TODO만 확인하고 종류 필터와 함께 사용할 수 있다.
- 시간이 있는 TODO에 사전 알림을 설정한다.
- 앱 종료 및 재실행 후에도 데이터가 유지된다.

## 핵심 사용자 흐름

### TODO 등록

1. 목록에서 추가를 선택한다.
2. 제목과 날짜를 입력한다.
3. 필요하면 시간과 복수 알림을 지정하고, Category를 선택하지 않으면 시스템 기본 Category `일반`을 사용한다.
4. 저장하면 선택 날짜의 목록에 표시된다.

### 날짜 및 필터 조회

1. 앱 실행 시 오늘 날짜를 표시한다.
2. 이전 또는 다음 날짜로 이동한다.
3. 필요하면 종류와 `미완료만 보기`를 함께 적용한다.
4. 활성화된 모든 조건을 만족하는 TODO만 표시한다.

### 완료 상태 변경

TODO를 완료 또는 미완료로 전환하고 화면에 즉시 반영한다. 미완료 필터가 활성화되어 있으면 완료한 항목은 결과에서 제외한다.

### 알림

날짜와 시간이 있는 TODO에 `1일 전`, `15분 전` 알림을 각각 또는 동시에 지정한다. 지정 시점에 Android 알림을 표시한다.

## MVP 기능 범위

### TODO

- 등록, 조회, 수정 및 확인 후 삭제
- 완료 및 미완료 상태 변경
- 필수 날짜와 선택 시간 지정

### 날짜와 필터

- 앱 실행 시 오늘 날짜 선택
- 이전·다음 날짜 이동
- 선택 날짜 조회
- 종류별 필터
- 미완료 필터
- 날짜, 종류 및 완료 여부의 AND 복합 필터

### 종류

- 모든 TODO에 정확히 하나의 Category 지정
- 변경·삭제할 수 없는 시스템 기본 Category `일반` 제공
- 사용자 Category 생성, 이름 수정 및 확인 후 삭제
- Category 이름은 시스템·사용자 구분 없이 중복 불가
- 사용 중인 사용자 Category 삭제 시 연결 TODO를 `일반`로 일괄 변경
- TODO 등록·수정 화면에서 Category를 선택하지 않으면 `일반` 사용
- `일반`을 항상 최상단에 고정하고 사용자 Category는 drag & drop으로 순서 변경
- 변경된 Category 순서를 로컬에 저장하고 모든 Category 목록에 동일하게 적용
- 시스템 기본 색상 또는 사용자가 선택한 사전 정의 색상으로 Category 표시
- Category 이름과 색상을 함께 표시하여 색상만으로 의미를 전달하지 않음

### 알림

- 시간이 있는 TODO에만 설정
- `1일 전(1440분)`, `15분 전` 제공
- 하나의 TODO에 복수 알림 허용
- 향후 다른 사전 알림 값을 추가할 수 있는 구조

### 데이터 유지

- Todo, Category와 Reminder를 로컬에 저장
- 앱 종료 및 프로세스 재실행 후에도 유지
- 저장된 Reminder로 시스템 알람을 재구성할 수 있어야 함

## 입력 정책

| 항목 | 필수 여부 | 정책 |
|---|---|---|
| 제목 | 필수 | 공백만 있는 값 불가 |
| 날짜 | 필수 | 유효한 달력 날짜 |
| 시간 | 선택 | 없으면 알림 설정 불가 |
| 종류 | 필수 | 미선택 시 시스템 기본 Category `일반` 사용 |
| 알림 | 선택 | 시간이 있을 때만 선택 |
| 완료 여부 | 시스템 관리 | 초기값은 미완료 |

## 주요 화면

1. **TODO 목록**: 날짜 이동, 목록, 완료 변경, 종류·미완료 필터, 등록·수정 이동
2. **TODO 등록/수정**: 제목, 날짜, 시간, 종류, 알림 입력 및 저장
3. **종류 관리**: 종류 추가, 이름 변경 및 삭제

## 빈 상태

- 선택 날짜에 항목이 없음: `등록된 TODO가 없습니다.`
- 활성 필터 결과가 없음: `조건에 해당하는 TODO가 없습니다.`
- 사용자 Category가 없어도 시스템 기본 Category `일반`은 항상 표시

## MVP 제외 범위

- 로그인, 회원가입 및 서버 API
- 클라우드·다기기 동기화
- 일정 공유와 Google Calendar 연동
- 반복 일정, 홈 화면 위젯 및 위치 기반 알림
- 시간이 없는 TODO의 알림
- 웹 및 iOS 버전

## 제품 완료 기준

1. `일반`이 최초 DB 생성 시 존재하고, 사용자 Category를 생성·수정·삭제·정렬할 수 있다.
2. 제목과 날짜가 있는 TODO를 등록·수정·삭제할 수 있다.
3. 시간을 선택적으로 지정하고 모든 TODO에 Category가 지정된다.
4. 시간이 있으면 두 알림을 각각 또는 동시에 설정할 수 있다.
5. 저장한 TODO가 해당 날짜에 표시된다.
6. 이전·다음 날짜로 이동할 수 있다.
7. 종류와 미완료 필터를 각각 또는 동시에 사용할 수 있다.
8. TODO를 완료 및 미완료로 변경할 수 있다.
9. 앱 재실행 후 데이터가 유지된다.
10. 지정 시점에 Android 알림이 발생한다.
11. Category 순서와 색상이 저장되고 앱의 Category 목록에 일관되게 표시된다.
